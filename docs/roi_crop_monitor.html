Key invariant
  • _tracked_balls is not None → Phase 2 active, YOLO skipped
  • _tracked_balls is None → rescan frame, YOLO runs
  • The rescan always happens exactly one frame after displacement is signalled
  • Robot footprint crops are skipped — never counted as missing

HSV Crop Check — check_ball_crops()

Location

perception/vision/pipeline.py · VisionPipeline

Per-ball steps
  • Convert ball.cm_x, ball.cm_y → topdown pixel via mapper.field_cm_to_topdown_pixel()
  • Check robot exclusion: if distance to robot center < robot_radius_px → skip (not counted as missing)
  • Clip crop to frame bounds: [cy−half : cy+half, cx−half : cx+half]
  • Convert crop BGR → HSV via cv2.cvtColor
  • Threshold with cv2.inRange(hsv, lower, upper)
  • Compute pixel_fraction = nonzero(mask) / mask.size
  • If pixel_fraction < crop_min_pixel_fraction → add to missing set
Robot exclusion math
robot_radius_px = robot_radius_cm × (w_frame / field.width_cm)
dist = √((cx − robot_px[0])² + (cy − robot_px[1])²)
dist < robot_radius_px → skip crop
Returns

set[int] of track_ids where ball was not found. Skipped crops are not included.

_tick_crop_monitor() — MainGUI

Location

Called every frame from tick() — runs before _tick_brain() so Brain sees the signal immediately.

Guards (early return if any fail)

Brain FSM — signal_ball_displaced()

Location

brain/brain.py · BrainController

New internal flag
_ball_displaced: bool = False

Set externally via signal_ball_displaced(). Checked at the top of tick() — before any state handler — so it fires regardless of current FSM state.

Tick() priority check
  • If _ball_displaced: clear flag, clear steps, reset cursor
  • Set _error_message = "ball_displaced"
  • Set _state = BrainState.ERROR
  • Call guidance.clear_route()
  • Log event and return immediately
State transitions
DRIVE → ERROR("ball_displaced")
IDLE → ERROR("ball_displaced")
ERROR("ball_displaced") → IDLE via load_route()
Flag cleared in
  • tick() — immediately on detection
  • load_route() — safety clear on new route
  • reset() — full state wipe

_replan_after_displacement() — MainGUI

Trigger condition (in _tick_brain)
  • _brain_state == BrainState.ERROR
  • brain.error_message == "ball_displaced"
  • _last_result.smoothed_ball_coordinates non-empty
  • _last_result.occupancy_grid is not None
  • robot_pose is not None

All conditions are met on the frame after displacement fires — that frame runs full YOLO because _tracked_balls was cleared.

Steps
  • Build PlannedBallTarget[] from fresh smoothed_ball_coordinates
  • Build HybridPose from current robot_pose
  • Get robot geometry from pose_estimator.robot_geometry_from_params()
  • Call _route_planner.plan_route(grid, targets, start, geometry)
  • If no route points → log + return (Brain stays in ERROR, operator must intervene)
  • Call brain.load_route(plan) — resets Brain to IDLE, clears error
  • Set _tracked_balls = new positions, clear _crop_missing_counts
  • Update _brain_route_points for schematic rendering
No reconnect needed

Commander and GuidanceController remain live. Only route changes. The robot does not stop — Guidance re-receives a new route and resumes.

pipeline.process() — skip_ball_detection

Location

perception/vision/pipeline.py · VisionPipeline.process()

New parameter
skip_ball_detection: bool = False
When True
  • YOLO inference is not called
  • white_balls = [], orange_balls = []
  • Ball masks are zeroed (np.zeros(...))
  • BallCoordinateSmoother.update([]) called — existing tracks age out normally
  • All other stages run unchanged: preprocessing, red-zone detection, occupancy grid
When False (default)
  • Full YOLO inference runs as before
  • All outputs populated normally
Decision logic in _process_frame()
skip = mode == AUTO and _tracked_balls is not None

Phase 2 (tracking)

  • skip = True
  • YOLO cost: 0 ms
  • HSV crops: ~<1 ms for 10 balls

Discovery / rescan

  • skip = False
  • YOLO cost: ~30–100 ms
  • Runs exactly once per rescan

Design Decisions & Rationale

Fixed crop centres — no position update
  • Balls that move enough to matter will leave the crop entirely — that's the signal
  • Small jitter stays within the crop and is ignored naturally
  • Avoids drift — no feedback loop that can lock on to the wrong pixel cluster
Error propagation through Brain FSM
  • No new states added — existing ERROR state reused with a specific message
  • Brain clears route and stops guidance atomically on the same tick as signal
  • MainGUI detects the specific error and auto-recovers; other errors still surface to operator
One-frame rescan delay
  • Displacement detected on frame N → _tracked_balls cleared → frame N+1 runs YOLO → replan on frame N+1
  • The robot is still executing guidance during this one frame — Guidance holds its last intent safely
Robot occlusion — skip not mask
  • If robot is over a crop → skip entirely, not counted as missing
  • Avoids false displacement trigger when robot picks up a ball (ball genuinely gone, but robot caused it)
  • Collection confirmation is a separate concern (patch tracking system)
HSV vs YOLO for crops
  • In a 60×60 px region the background is mostly green floor — white ball is distinctive
  • HSV threshold is ~0.001 ms per crop vs ~50 ms for full YOLO
  • Sliders (crop_white_h/s/v_min/max) allow per-session tuning for lighting conditions
